# Data provenance and sharing check

This package contains the exact files read by the framework notebook. The flow and nitrate observation files, Soilscapes data, BGS hydrogeology data, model configuration and WWTW records originate from source systems described in the dissertation. Before changing this private repository to public, confirm that each dataset's licence, access conditions and attribution requirements permit redistribution.

The package preserves the WSIMOD source licence at `wsimod-staged-calibration-framework_inputs/wsimod_source/LICENSE`. It does not claim ownership of third-party data or source code.
